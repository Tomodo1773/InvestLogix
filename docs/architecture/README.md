# InvestLogix architecture diagram

This directory contains the source and exported assets for the production structural architecture diagram.

- `architecture.html`: self-contained editable source
- `architecture.svg`: exported vector image
- `architecture.png`: exported 1600 x 900 raster image
- `SOURCES.md`: provenance and usage notes for brand assets

The arrows represent major dependencies and interactions, not a complete request/response sequence.
